================================================================================

프로젝트 개요:
-------------
WebPilot은 AI 기반 웹 자동화 에이전트 시스템입니다.
멀티모달 인식, 도메인 분류, 좌표 클릭 등의 기능을 통해
웹 페이지를 자동으로 탐색하고 조작하는 에이전트입니다.

================================================================================
                            주요 컴포넌트 설명
================================================================================

1. Planner Agents (계획 에이전트)
   --------------------------------
   - Domain_Priority_Classifier_Agent: 
     웹 페이지의 도메인을 분석하고 우선순위를 매기는 에이전트
     
   - VLM_Coordinate_Clicker: 
     Vision-Language 모델을 사용하여 이미지에서 클릭할 좌표를 찾는 에이전트

2. Executor Agents (실행 에이전트)
   --------------------------------
   - multimodal_perceiver_agent: 
     텍스트와 이미지를 모두 인식하고 처리하는 멀티모달 에이전트
     
   - navigation_agent: 
     웹 페이지 네비게이션을 담당하는 에이전트

3. Configuration (설정)
   ----------------------
   - constants/: 전역 상수 정의
   - config/: YAML 기반 설정 파일들

4. Test Suite
   -----------
   - API 키 검증
   - Playwright 브라우저 자동화 테스트
   - Vision-Language 모델 성능 테스트

================================================================================
                            기술 스택
================================================================================

Core Technologies:
- Python 3.11
- OpenAI GPT-4o (Vision 포함)
- Playwright (브라우저 자동화)
- CLIP (Vision-Language 모델)
- PyTorch (딥러닝 프레임워크)

주요 라이브러리:
- PIL/Pillow (이미지 처리)
- requests (HTTP 통신)
- PyYAML (설정 파일 파싱)
- FastAPI (웹 프레임워크)
- LiteLLM (LLM 통합)

================================================================================
                            데이터 플로우
================================================================================

1. 사용자 입력 → WebPilot Main Agent
2. Domain Priority Classifier → 도메인 분석 및 우선순위 결정
3. Multimodal Perceiver → 페이지 시각적 분석
4. VLM Coordinate Clicker → 클릭 대상 좌표 탐지
5. Navigation Agent → 브라우저 조작 실행
6. 결과 반환 및 다음 액션 계획

================================================================================
                            개발 가이드라인
================================================================================

1. 모든 에이전트는 agent.py와 prompt.py를 포함해야 함
2. 프롬프트는 각 에이전트의 prompt.py에서 관리
3. 공통 상수는 constants/constants.py에 정의
4. 도메인별 설정은 config/domains.yaml에서 관리
5. 테스트는 Test/ 디렉토리에서 진행
